Локальный Compose и штатный деплой на VPS загружают демовыпуск после миграций.
Для ручной загрузки из корня backend:

```bash
docker compose exec -u www-data app php bin/console doctrine:fixtures:load --group=demo-digest --append
```

Команда доступна и в production-образе. Для запуска через локальный PHP
выполните `composer install` и ту же команду без префикса `docker compose exec`.
Группа `demo-digest` выбирает этот набор, а флаг `--append`
сохраняет существующие данные. Повторный запуск распознаёт выпуск по ID
исходного запуска Go. Фикстура сохраняет выпуск как опубликованный,
без запросов к модели и без создания рассылки.
