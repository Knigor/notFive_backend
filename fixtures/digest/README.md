# Сохранённый выпуск Go для локальной базы

`2026-11-08/` содержит результат реального запуска Go `1d61c155ce11088f15b2427cd892df82`: 12 публикаций, 5 выбранных событий и четыре готовых файла. Контрольное время — **8 ноября 2026, 18:26:08 МСК**, окно — `(7 ноября 18:26:08, 8 ноября 18:26:08]`. Для публичного API дата выпуска — `2026-11-08`.

Данные взяты из сохранённого `var/exports/notfive-pipeline-2026-11-08` и локального аудита `/tmp/notfive-pipeline-audit.json`. В фикстуре нет ключей, HTTP-заголовков, внутренних запросов к провайдеру и идентификатора каталога Yandex.

- `news.json` и `analysis.json` — исходные сохранённые результаты без правки текстов и дат.
- `result.json` — анализ и текстовый ответ Alice, преобразованные в текущий camelCase-контракт Symfony `GoDigestResult`. Из URI модели оставлено её имя; версии промптов, расход токенов и длительности взяты из аудита.
- `files/` — исходные `digest.md`, `post.md`, `email.md`, `journal.csv`, без повторной генерации.
- `manifest.json` — идентификатор и время исходного запуска, SHA-256 исходного аудита, тема письма и предупреждения.

Это сохранённый результат прототипа, а не проверенный эталон. Предупреждения оставлены: событие G4 требует проверки источника, семь материалов модель пропустила. Тексты и журнал не исправлялись вручную.

Из корня репозитория с запущенным локальным Compose и выполненными миграциями:

```bash
docker compose cp fixtures/digest/2026-11-08 app:/app/var/datasets/
docker compose exec app php bin/console digest:load-fixture /app/var/datasets/2026-11-08
```

При запуске PHP непосредственно на машине:

```bash
php bin/console digest:load-fixture fixtures/digest/2026-11-08
```

Команда добавляет опубликованный выпуск, материалы, события, источники, цитаты, решения журнала, метаданные модели и четыре артефакта. Она не очищает базу, не обращается к модели и не отправляет рассылку. Повтор с тем же ключом и содержимым возвращает существующий запуск. Изменение содержимого уже загруженной фикстуры отклоняется; перезаписи опубликованного выпуска нет. Путь исходного JSON в `run_inputs.locator` указывает на каталог фикстуры; приведённые команды копируют его в постоянный том `dataset_files`.

Проверка публичного GraphQL:

```bash
curl --fail-with-body http://localhost:8080/api/graphql \
  -H 'Content-Type: application/json' \
  --data '{"query":"{ digest(date: \"2026-11-08\") { runId controlTime periodStart totalMaterials events { rank title summary consequences selectionReason sources { name url publishedAt } } files { digest post email csv emailSubject } } }"}'
```

Четыре файла возвращаются строками в `files`; источники событий — в `events[].sources`. Дата `2026-11-07` не выбирает этот выпуск: API фильтрует по московскому дню контрольного времени.
